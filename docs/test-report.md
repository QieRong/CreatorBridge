## 3. 功能模块测试细节与抓取日志

### 3.1 四平台预览差异性展示

一键适配触发后，CDP 成功读取到 4 个平台独特的预览内容：
- **微信公众号 (Wechat)**:
  * **标题**: `深度解读：高效创作指南`
  * **排版特质**: 添加了 `【导语】` 段落，结尾包含重点加粗总结，语气正式规范。
- **知乎 (Zhihu)**:
  * **标题**: `如何评价「高效创作指南」？`
  * **排版特质**: 以 `谢邀。` 经典句式开头，且正文使用双星号 `**核心结论**` 的 Markdown 加粗语法。
- **B站 (Bilibili)**:
  * **标题**: `【干货预警】高效创作指南！看完直接起飞！`
  * **排版特质**: 正文引入 `🌟 本期看点：\n▶` 等年轻化导读，结尾包含“一键三连”的互动引导。
- **小红书 (Xiaohongshu)**:
  * **标题**: `🔥 高效创作指南 ✨`
  * **排版特质**: 段落中穿含 `家人们！`、`📌` 等口语化修辞与 emoji 符号，结尾将标签转换成了 `#话题`。

### 3.2 敏感数据脱敏检索详情
测试脚本对导出的 JSON 载荷文件进行了读取，通过正则表达式 `/token|cookie|appSecret|password|secret|credential/i` 进行全局扫视。扫描结果：
- **token**: `0 匹配`
- **cookie**: `0 匹配`
- **appSecret**: `0 匹配`
- **password**: `0 匹配`
- **secret**: `0 匹配`
- **credential**: `0 匹配`

本次导出的 Payload JSON 中未检出 token、cookie, appSecret, password, secret, credential 等敏感字段，这与本项目的“不做真实发布接口，不保存任何真实密钥”的轻量化安全边界保持一致。

### 3.3 运行期 Console 报错监控
测试工具链开启了对 Chrome 内核事件的全局长连接订阅。在自动化交互操作中，测试中暂未检出 JavaScript 控制台异常。
