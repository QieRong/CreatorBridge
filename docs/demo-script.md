# CreatorBridge 演示脚本

> 总时长控制在 2 分钟以内，行文保持严谨、客观，无多余字眼。
> 演示大纲顺序：一键适配 → 多平台预览 → Payload JSON 导出 → Connector 预留说明 → 模拟发布 → 发布历史。

## 1. 开场（约 10 秒）

**展示项目首页**

"大家好，这是我的暑期实训营参赛项目——CreatorBridge，多平台内容适配发布助手。"

"它解决的问题是：创作者需要在公众号、知乎、B站、小红书等多个平台同步发布内容，但各平台排版规范和风格不同，手动适配非常繁琐。"

"CreatorBridge 的核心设计理念是：写一次，到处发。"

## 2. 输入内容与平台选择（约 20 秒）

**在输入区填写原始内容并勾选四个目标平台**

1. 标题输入：`高效学习方法：如何用费曼技巧提升理解力`
2. 正文输入：输入关于费曼学习法的简短介绍（约 200 字）
3. 标签输入：`学习方法,费曼技巧,效率提升,知识管理`
4. 目标平台：全选「公众号」、「知乎」、「B站」、「小红书」

"我先在输入区填入一篇关于费曼学习法的原始内容，包括标题、正文、标签。然后勾选要发布的目标平台，这里我们全选四个平台。"

## 3. 一键适配与预览差异（约 30 秒）

**点击「一键适配」按钮，滚动到预览区，展示平台转换效果**

"点击一键适配，系统自动将统一模型转换为各平台的专属版本。"

"我们可以看到预览卡片中的文风与格式差异："
* **公众号**：标题格式完整，正文自动转化为具有“导语、分段正文、重点总结”的正式长文。
* **知乎**：标题转换为问题式，开头引入“谢邀”问候，正文自动排版为 Markdown 格式分点论证。
* **B站**：标题加入干货引导语，自动提取核心看点并添加一键三连的互动文案。
* **小红书**：标题缩短并点缀 emoji，正文转化为口语化安利风，标签也对应重组为 #话题。

"同时，系统进行了多层级格式校验，能显示 error、warning、info 警示，协助创作者快速修复排版缺陷。"

## 4. Payload JSON 载荷导出展示（约 20 秒）

**展示下方的“统一发布载荷 (PublishPayload)”卡片**

1. 演示动作：点击“复制 Payload”按钮，粘贴到文本软件进行展示。
2. 演示动作：点击“导出 Payload JSON”按钮，下载 `.json` 文件。

"一键适配后，系统在下方同步生成了标准的 `PublishPayload` 统一载荷 JSON。数据结构已进行完全脱敏处理。我们支持一键复制，也支持一键导出为本地 JSON 文本文件，便于离线中转或手工分发。"

## 5. 发布模式与 Connector 连接器预留说明（约 20 秒）

**在“发布模式与连接器预留”卡片进行交互展示**

1. 演示动作：点击模式卡片中的“Connector 自定义连接器”选项，展示展开的说明面板。
2. 演示动作：在“API Base URL 预留输入框”中输入测试 URL。

"为了说明后续接入真实发布的设计思路，项目设计并预留了 Connector 自定义连接器模式。切换到此模式时，可以看到 API Base URL 预留输入框和安全提示。我们本阶段不发起真实网络请求，亦不提供 Token 框，避免在前端保存敏感凭证，防范配置残留风险。真实发布需要用户自建后端中转服务，并取得平台授权。"

## 6. Mock 模拟发布与历史归档（约 15 秒）

**切换回“Mock 模拟发布”模式，点击“模拟发布”按钮，展示发布历史**

1. 演示动作：点击“模拟发布”按钮，卡片中正常呈现发布结果列表。
2. 演示动作：展示下方的“发布历史”列表。

"切换回 Mock 模式，点击模拟发布，系统会生成唯一的发布批次号，展示每个平台的模拟发布状态，并写入本地发布历史中。发布历史会保存在浏览器本地存储中，方便创作者追溯之前的发布记录。项目也支持一键清空历史。"

## 7. 结束（约 5 秒）

"以上就是 CreatorBridge 多平台内容适配发布助手的全部演示。当前阶段各项功能运行稳定，保持良好的架构兼容性。感谢聆听！"

### 示例正文
```
费曼学习法是诺贝尔物理学奖得主理查德·费曼提出的学习方法。它的核心理念是：如果你不能用简单的语言解释一个概念，说明你还没有真正理解它。

这个方法分为四个步骤：
第一步，选择一个你想学习的概念。
第二步，尝试用最简单的语言向一个完全不懂的人解释这个概念。
第三步，找出你解释不清楚的地方，回到原始资料重新学习。
第四步，简化你的解释，直到一个小学生也能听懂。

通过不断重复这个过程，你对概念的理解会越来越深入。这种方法不仅适用于学术学习，也适用于工作中的技能掌握。
```
